Problem 2: Multi-class Classification – Monthly Marijuana Frequency

Cross-validation and Pruning

cv_tree <- cv.tree(reg_tree)
plot(cv_tree$size, cv_tree$dev, type = "b")

best_size <- cv_tree$size[which.min(cv_tree$dev)]
reg_pruned <- prune.tree(reg_tree, best = best_size)
pruned_pred <- predict(reg_pruned, newdata = test)
pruned_mse <- mean((test$IRMJFY - pruned_pred)^2)
cat("pruned test MSE:", round(pruned_mse, 2), "\n")
## pruned test MSE: 10157.17

To avoid overfitting, we used cross-validation to select the optimal tree size. The plot shows the test deviance decreasing sharply until a tree size of 3, The optimal tree size chosen was 3, balancing model complexity and performance.The pruned tree’s test MSE improved slightly to 10,157.17, compared to 10,280.03 for the unpruned tree.
